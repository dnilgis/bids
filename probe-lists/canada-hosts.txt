# CANADIAN GRAIN BUYERS, FOR scripts/discover.mjs --list
#
# discover loads each page in a real browser and records WHICH platform it runs
# and WHAT id its own widget asks for. That is the only way to get a DTN site id
# — DTN answers a server-side probe with "the api key is valid, but it is valid
# to be used within a browser only" — and it is how every DTN line in
# dtn-sites.txt was found.
#
# PROVENANCE, IN TWO GRADES, BECAUSE THEY ARE NOT THE SAME THING.
#
#   [seen]   A bid table was loaded and read on this domain. Four of them.
#   [named]  The company and the domain came off a real page — a trade body
#            roster, a buyer directory, its own site — and the bid page was
#            either behind robots.txt, rendered by script with no server HTML,
#            or behind a login. NOT a constructed URL, and NOT proof of a board.
#
# THE ROBOTS WALL IS WHY SO MANY ARE [named]. Every AgriCharts and Bushel
# customer disallows the path its board lives on. That is a rule about crawlers,
# not evidence the board is missing, and discover loads pages the way a person
# does. It is also exactly why this is a button and not a schedule.
#
# CURRENCY AND UNITS, WHICH ARE THE WHOLE JOB HERE:
#   Ontario quotes CAD per bushel, mostly. Two of the four [seen] sites publish
#   BOTH a per-bushel and a per-tonne column, so a reader must pick a column
#   rather than take the first number in the row.
#   Quebec and the Maritimes lean CAD per TONNE. Ansems states it outright.
#   The Prairies are mixed BY COMMODITY, not by company: cereals and oilseeds
#   per bushel, pulses per pound, some contracts per tonne.
# None of that is a reason not to read them. All of it is a reason nothing here
# publishes until its manifest says which money and which unit.
