# AGRICHARTS OPERATORS BARCHART CARRIES AND WE DO NOT — 2026-09-03
#
# 61 sites, 70 operators, 394 Barchart facilities.
# 60 of those sites have never been asked: 360 facilities.
#
# WHERE THE LIST CAME FROM. The Barchart coverage gap measured 2026-09-03:
# 1,801 facilities Barchart carries, 258 of them read by this repository. Of
# the 1,543 uncovered, 494 sit behind a platform this repo ALREADY HAS AN
# ADAPTER FOR, and 394 of those 494 are AgriCharts. That is the largest block
# of elevators in the country reachable with no new parsing code at all — the
# adapter, the quote pages and the identity check exist and already read 84
# boards.
#
# WHY THE SWEEP HAS NOT ALREADY ASKED THEM. agricharts-sweep.mjs takes its
# sites from data/platforms.json, which holds what the discover runs happened
# to visit. None of the eight largest operators here are in it, and of the 124
# mobile candidates these 61 sites generate, exactly ONE is on
# probe-lists/agricharts-mobile.txt. The sweep has not asked them because
# nothing ever put them in front of it.
#
# ONE LINE IS NOT LIKE THE OTHERS. www.farmersco-operative.com is a master
# board serving 10 co-operatives with 34 facilities between them, and
# farmersco-operative.mobile.agricharts.com IS ALREADY READ — it is one of the
# 84. Those 34 facilities are not a sweep problem: they are locations on a
# board we read whose manifests were never written, which means the directory
# join could not give them a town. Asking again is harmless (the sweep never
# overwrites and never invents a town) and the run will say so in its unmatched
# list, which is where that queue belongs. Discount it from what a sweep can
# win: 360, not 394.
#
# THE FACILITY COUNTS ARE BARCHART'S, NOT OURS. The number after each site is
# how many facilities Barchart carries for that operator that we do not read.
# The sweep finds its own locations from the board and refuses any it cannot
# give a town to. Treat these as a ceiling.
#
# TO RUN IT: Actions -> agricharts sweep -> Run workflow, and in the box
# labelled `hosts` put just the file name:
#
#     agricharts-uncovered-2026-09-03.txt

# front -- run 91604425422 pasted `hosts = probe-lists/...` because that is

# forgiving now; the instruction is clearer.)
