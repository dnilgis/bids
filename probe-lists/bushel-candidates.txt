# ── NINE MORE CHS REGIONS, found 2026-08-26 ────────────────────────────────
# CHS has no public directory of its regional co-operatives -- chsinc.com/locations
# is a 404 -- so these were found a different way, and the method is worth keeping.
#
# Every CHS regional site is one WordPress multisite on a shared `chs-theme`. The
# rendered page is JavaScript-only and carries no platform string, but the REST
# API hands back the raw markup:
#
#     https://<region>.com/wp-json/wp/v2/pages?slug=cash-bids
#
# and `content.rendered` contains, verbatim:
#
#     <div id="cash-bids-root" data-locations="W10,W20,W30,...">
#     <script src=".../chs-theme/dist/js/bushel/cash-bids-front-end.DINZfkbf.js">
#
# `bushel` in the asset path, and THE SAME BUNDLE HASH on every site -- so it is
# provably the identical widget the fourteen regions we already read are served
# by, not a guess from a family resemblance. An empty data-locations array is a
# clean negative, which is how CHS Northwest was ruled out rather than assumed.
